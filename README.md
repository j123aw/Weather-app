# Weather App

This repository contains a Weather application with both web and Python components.

## Components

### Web Application
- **Location**: `public/` directory
- **Files**: 
  - `index.html` - Main HTML interface
  - `script.js` - JavaScript for fetching weather data
  - `weather.css` - Styling
- **Description**: A web-based weather app that fetches current weather data using the OpenWeatherMap API

### Python Dictionary Examples
- **File**: `weather_dictionary.py`
- **Description**: Comprehensive Python code demonstrating dictionary operations using weather-related examples

## Running the Python Dictionary Examples

To run the Python dictionary demonstrations:

```bash
python3 weather_dictionary.py
```

## What's Covered in weather_dictionary.py

The Python file demonstrates:

1. **Creating Dictionaries** - Different ways to create and initialize dictionaries
2. **Accessing Values** - Using bracket notation and get() method
3. **Modifying Dictionaries** - Adding, updating, and removing items
4. **Dictionary Methods** - keys(), values(), items(), update(), clear()
5. **Nested Dictionaries** - Working with complex data structures
6. **Dictionary Comprehension** - Creating dictionaries with concise syntax
7. **Checking Key Existence** - Using 'in' keyword and safe access patterns
8. **Default Values** - Using setdefault() for safe defaults
9. **Practical Examples** - Weather station data management
10. **Copying Dictionaries** - Shallow vs deep copying

## Web Application Setup

The web application uses Firebase for hosting. Configuration files:
- `.firebaserc` - Firebase project configuration
- `firebase.json` - Firebase hosting settings

To deploy the web app, use Firebase CLI tools.
